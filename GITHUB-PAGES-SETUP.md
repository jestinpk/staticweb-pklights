# PK LIGHTS GitHub Pages Setup

This package is configured for:

`https://pklights.in/`

## Upload

1. Extract the ZIP file.
2. Upload all extracted files and folders to the `main` branch of `jestinpk/staticweb-pklights`.
3. Make sure `.github/workflows/deploy-pages.yml` is included.
4. In repository **Settings → Pages**, select **GitHub Actions** as the source.
5. Open the repository **Actions** tab and wait for **Deploy PK LIGHTS to GitHub Pages** to finish.

After the workflow succeeds, open:

`https://pklights.in/`
